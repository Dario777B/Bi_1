# Sistemas de Información para la Inteligencia de Negocios

Sitio educativo estático para la Universidad Técnica de Cotopaxi:

- `index.html`: presentación interactiva de 11 diapositivas sobre el sílabo.
- `dashboard.html`: dashboard ficticio de Liga Pro 2026, con gráficas y tabla de posiciones.
- `juego.html`: aventura BI de cuatro salas protagonizada por el robot dragón Briz.

Abre `index.html` en un navegador o sirve la carpeta con un servidor estático. La presentación se navega con los botones inferiores, los puntos, las flechas izquierda/derecha, AvPág/RePág o Inicio/Fin. Bootstrap y las fuentes se cargan desde CDN.
