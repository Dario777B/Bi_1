# Sistemas de Información para la Inteligencia de Negocios

Sitio educativo estático con tres experiencias:

- `index.html`: fundamentos de BI, proceso ETL y cuestionario gamificado.
- `dashboard.html`: dashboard ficticio de Liga Pro 2026, con gráficas interactivas y tabla de posiciones.
- `juego.html`: aventura educativa de cuatro salas protagonizada por el robot dragón Briz.

Abre `index.html` en un navegador o sirve la carpeta con un servidor estático. Bootstrap, Chart.js y la tipografía Inter se cargan desde CDN, por lo que requieren conexión a internet.
