# Sistemas de Información para la Inteligencia de Negocios

Sitio educativo estático para la Universidad Técnica de Cotopaxi:

- `index.html`: inicio con fundamentos BI, cuestionario y botones de navegación.
- `dashboard.html`: dashboard ficticio de Liga Pro 2026, con gráficas y tabla de posiciones.
- `juego.html`: aventura BI de cuatro salas protagonizada por el robot dragón Briz.
- `silabo.html`: presentación interactiva de 11 diapositivas sobre el sílabo UTC.

Abre `index.html` en un navegador o sirve la carpeta con un servidor estático. Accede al sílabo con el botón «Sílabo UTC» en la navegación. La presentación se maneja con los botones inferiores, los puntos, las flechas izquierda/derecha, AvPág/RePág o Inicio/Fin. Bootstrap y las fuentes se cargan desde CDN.
